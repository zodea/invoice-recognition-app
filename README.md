# 发票识别与送货单整理助手

本地运行的 Vue + Tauri 应用，用于送货单扫描件整理、发票识别核对、批量打印排版和 Excel 汇总。

## 正式版开发分支

`stable` 是当前 0.3.12 起使用的正式版开发分支，后续直接在此修改、验证、提交并推送，不为每次更新另开分支。`main` 保留此前包含项目、工人和 SQLite 等模块的另一套版本，暂不调整或合并。

## 功能

- 发票 PDF / 图片导入，支持电子发票文本抽取和扫描件 OCR。
- 发票左右核对：左侧打印排版预览，右侧识别字段编辑。
- 发票批量打印 PDF、开票明细和汇总账单 Excel。
- 送货单扫描件识别（横向/竖向扫描由 PaddleOCR-VL 自动转正）、分区整理和导出。
- Tauri 桌面应用打包。

## 0.3.8 复核与费用管理

- 公司 / 工地配置：新增购买方和工地，维护厂家对应关系，按公司、工地及厂家查看费用。加油和个人报账独立归属，其他未明确归属的费用待确认；本版不做多工地分摊。
- 历史进项台账的编辑按钮打开原件对照编辑；填写完整并确认原件后保存。发票号码为关联标识，不能在此直接改号。
- 报销导入选择 Excel 或已解压目录，先预览再确认。只更新已有台账匹配项，冲突和未找到的号码不新增发票；路径中的季度或日期区间保存为报销期间，不推算具体报销日期。
- 付款凭证独立导入垫资清单与图片，截图按日期和金额找候选，人工核对收款方；日期、金额和截图 SHA-256 一致时阻止重复保存。缺少截图或尚未确认的记录在导航及付款页面持续提醒。截图不同仅视为待核对，不自动合并。
- 付款表含多行材料时保留付款汇总金额并合并费用名称，退款保留原值供核实；付款只有确认截图后才计入汇总。注意避免将已有发票的同一费用再次登记为无票付款。
- 数据保存在当前应用本机；原始目录和旧安装包不改动。构建产物位于 dist 和 Cargo 配置的 target/release/bundle/nsis（本机为 D:/Cargo/target/release/bundle/nsis）。

## 0.3.9 导出目录修复

行程单、医疗票据直接存入导出根目录下的同名类型文件夹，不按购买方、销售方或日期再次嵌套；普通/专用发票继续遵循所选分目录规则。行程单不强制购买方与发票号码，医疗票据不强制购买方，日期、金额等校验仍保留。

## 0.3.10 交互和档案完善

打印设置与更多导出互斥，执行导出前收起，防止重复触发。票种与发票状态统一使用标签；有勾选时间只展示时间，无时间且确认抵扣时显示已抵扣。基础档案可配置报销人、用途、标签和付款方式，复核表单可检索选择。自定义标签仅用于检索和导出；有效抵扣税额只匹配税务清单，缺失时不推算。

## 0.3.11 购买方排查与列表精简

- 在基础档案添加购买方公司后，可点击“一键排查台账购买方”，查看购买方未填写或不在档案中的历史发票。发票管理也提供当前批次排查入口，一键排查会清除其他筛选，避免漏看记录；后续可叠加日期等筛选。
- 检查使用最新档案与票据信息，忽略空格、全半角等格式差异，不做名称模糊匹配。行程单和医疗票据不参与购买方检查。待核对是本地档案匹配提示，不代表票据无效，也不会自动改写票据。
- 购买方候选仅来自手动添加的公司档案，不再收集历史识别结果。原有购买方仍保留供对照核实。
- “厂家对应关系”改为“厂家与费用归属”，增加用途说明。
- 台账列表隐藏费用名称、备注，保留付款账户；公司、购买方、工地及付款账户长文本保留首尾，中间省略，悬停显示全文。详情和导出仍保留原字段。
- 打印与导出设置弹窗缩窄，去掉文件夹显示顺序的提示。

## 0.3.12 删除与恢复

- 基础档案中的购买方、工地新增“删除”按钮，删除后可在“已删除档案”中恢复。已有票据的名称不改写；涉及被删购买方或工地的厂家归属规则停用，恢复档案后重新启用。
- 历史台账支持单张删除、勾选后批量删除和全选当前页。翻页可继续勾选，筛选后隐藏的记录自动取消勾选。删除前确认数量。
- 删除记录和“清空历史台账”均移入本机回收站，保留原件与所有字段，退出台账汇总、查重与导出；可单张或按回收站筛选结果恢复。同号码已重新导入时不覆盖现有台账。回收站不自动清空，保留至用户恢复。
- 每次更新验证通过后提交 commit，并推送当前远程分支。
- 档案删除、单张/批量删除及清空台账使用软件内确认弹窗，显示操作范围并提供取消；不再调用浏览器原生确认框。

## 0.3.13 紧凑台账与回收站清理

- 历史台账顶部统计与按钮缩小间距，报销导入改为独立弹窗；列表标题和购买方排查合并，筛选标签横排，表格行、汇总及分页缩小高度，让清单获得更多显示空间。
- 发票回收站不设到期时间、不自动清理。支持单条永久删除及清空全部回收站，操作前在软件内确认数量和不可恢复后果。
- 永久删除同时清理软件内不再被有效台账或其他回收站记录引用的原件副本，不删除电脑原文件夹中的文件。原件清理失败时保留重试队列，在回收站显示“重试原件清理”。

- 基础档案右上角集中提供档案清单、厂家归属清单、档案回收站；主页面只保留表单与费用汇总，不随档案数量持续扩展。清单按每页 8 项展示，支持名称搜索与档案类型筛选，长名称保留首尾、中间省略。
- 档案回收站支持恢复、单项永久删除和清空全部。永久删除只移除备份，不改写历史票据；关联的停用规则可在厂家归属清单移除。
- 档案保存、删除与恢复使用全局浮动消息，成功提示约 4 秒后自动消失，不再常驻占用页面空间。

本版界面验证使用内存模拟数据，预览图保存在本地 `release-output/`（不提交）：1280×800 窗口可完整显示约 10 行台账；档案清单每页 8 项，65 项以上数据仍按页展示。成功消息已验证自动消失。

## 0.3.14 票据入账确认

- 识别结果先与购买方档案核对，支持先保存已匹配发票，留下异常票据二次确认。
- 其他票据转入付款凭证，保留原件、原始识别信息和标签，不进入历史进项台账。
- 行程单可人工关联主发票，在发票详情切换查看，关联后不重复计入费用。
- 已通过 npm test 和生产构建。未处理的本批识别结果仍使用当前会话队列，关闭应用前需完成处理。

## 0.3.15 分供方档案与紧凑核对提示

- 新建分供方先选择大宗供应商、甲供材分供方、公司分供方、房东或零星供应商，再显示对应的双列表单。支持草稿、后补附件、联系人及开票信息；全称、简称、开票名称和识别别名用于唯一精确匹配，有歧义时由用户选择。
- 批量导入保留原模板全部字段，并补充分供方类型、工地、识别别名，共 32 列。模板提供类型、类别、评价、纳税人类型、班组个人、工地、上级供应商 7 组下拉，工地与上级供应商在下载时带入当前档案。银行账号和识别号按文本保存；错误行单独报告，已有档案只补空字段并保留采购、付款和附件。
- 工地候选统一使用有效档案，不再将历史识别的个人、住宿等文字混入候选；单价对比与送货单分区同步档案工地。费用归属支持自建归属、指定工地和手动采用厂家归属规则。
- 发票详情标题右侧显示小型“问题”标签，悬停或键盘聚焦查看原因；移开后收起，不再插入大块说明。保存、转为其他票据、关联行程单等操作放在“更多”浮层，表单位置保持不变。
- 验证包括 npm test、生产构建、Windows 安装包构建，以及虚构数据下的五类表单、共享工地、费用归属、入账分流和问题提示交互。Excel 下拉已验证文件结构和导入往返，未在原生 Excel 中逐项点选验证。
- 模板生成源为 scripts/build-supplier-template.mjs，运行时空白模板为 src/assets/supplier-import.xlsx。用户原始模板、业务资料及本机界面验证截图不提交。
